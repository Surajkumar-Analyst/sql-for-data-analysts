# LeetCode SQL Practice

A daily log of SQL problems solved on LeetCode, tracked as part of my data analyst prep. Each solution is organized by problem name and includes the original question along with my query.

## 📌 About

I'm solving SQL questions on LeetCode consistently to sharpen my query-writing skills for data analyst roles — covering joins, aggregations, window functions, subqueries, and common interview patterns.

## 📁 Structure

Each solved problem gets its own folder at the repo root, named after the LeetCode problem number and title. Inside, a `.sql` file holds the accepted query, and a `README.md` holds the problem statement, link, and notes.

```
sql-for-data-analysts/
├── 0185-department-top-three-salaries/
│   ├── 0185-department-top-three-salaries.sql   → my accepted query
│   └── README.md                                 → problem statement + link + notes
├── 0176-second-highest-salary/
│   ├── 0176-second-highest-salary.sql
│   └── README.md
└── ...
```
